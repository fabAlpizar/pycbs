Basis Sets
==========

.. _basis_sets:

Overview
--------

The program supports the following Gaussian basis sets.
All names are case-insensitive and correspond to the internal
hierarchical number definitions used for extrapolation.

Supported Basis Sets
--------------------

Minimal Basis Sets
~~~~~~~~~~~~~~~~~~

- STO-2G
- STO-3G
- STO-6G

Minimal / Compact Variants
~~~~~~~~~~~~~~~~~~~~~~~~~~

- MINI
- MINI-s
- MIDI
- MIDI!

Pople Basis Sets
~~~~~~~~~~~~~~~~

- 3-21G
- 3-21++G
- 3-21GSP
- 4-22GSP
- 4-31G

Correlation-Consistent (Dunning) Basis Sets
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Double-zeta
^^^^^^^^^^^

- VDZ  (cc-pVDZ)
- AVDZ (aug-cc-pVDZ)
- d-AVDZ (d-aug-cc-pVDZ)

Triple-zeta
^^^^^^^^^^^

- VTZ  (cc-pVTZ)
- AVTZ (aug-cc-pVTZ)
- d-AVTZ (d-aug-cc-pVTZ)

Quadruple-zeta
^^^^^^^^^^^^^^

- VQZ  (cc-pVQZ)
- AVQZ (aug-cc-pVQZ)
- d-AVQZ (d-aug-cc-pVQZ)

Quintuple-zeta
^^^^^^^^^^^^^^

- V5Z  (cc-pV5Z)
- AV5Z (aug-cc-pV5Z)
- d-AV5Z (d-aug-cc-pV5Z)

Higher-Order Dunning Sets
~~~~~~~~~~~~~~~~~~~~~~~~~~

- V6Z  (cc-pV6Z)
- AV6Z (aug-cc-pV6Z)
- V7T  (cc-pV7Z)

F12-Optimized Basis Sets
~~~~~~~~~~~~~~~~~~~~~~~~~

- VDZ-F12  (cc-pVDZ-F12-OptRI)
- VTZ-F12  (cc-pVTZ-F12-OptRI)
- VQZ-F12  (cc-pVQZ-F12-OptRI)
